Running log of all architectural and product decisions, appended at the end of each phase per the working agreement. New or changed decisions are added here; superseded decisions are marked, never deleted.

**Recap for new conversations:** 12 decisions exist (D-001…D-012), all originating in Phase 1 (Product Requirements). Headline calls: shared-schema + RLS tenancy (shard-ready), one dedicated WABA/number per firm via direct Cloud API, 24-hour-window-first messaging, mirror-the-client language handling (EN/UR/Roman Urdu), tiered AI data posture (T1/T2/T3) governing what reaches third-party LLMs, cost-tiered model routing with fallback chains, hosted Whisper behind a port, multi-rail payments (JazzCash/Easypaisa/card/intl + offline), and AI boundaries (disclosure, no legal conclusions, deterministic hard-escalation triggers) as testable requirements.
